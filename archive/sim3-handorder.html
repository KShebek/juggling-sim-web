Sim 3 · Hand order

Free timing, like sim 2, but you choose which hand throws, and flip sends any throw to the other destination: a 4 that crosses, a 3 that stays. The autopilot can start in any vanilla, handswap or sync pattern.

Start pattern (autopilot)

Hand order
Vanilla (531, 744), sync ((4,4), (6x,4)*, (4,2x)*) or a vanilla pattern with a handswap hand order (2 = RLRL, 13 = RRLL, 123 = RRLRRL; ignored for sync). Values a–z = 10–35. No multiplex yet. Press Enter to apply.

Balls (shortcut)

Sets the start pattern to N (cascade / fountain). Keys: - / =

Settings

A throw of value v flies for (v − dwell) beats at this tempo. Your own timing is free.

Visual aids

Controls

Every throw happens now. Normally odd values cross and even values stay. Hold flip for that hand and the throw goes the other way. The hand order is simply whichever hand you throw from. Both hands can throw at once (sync).
